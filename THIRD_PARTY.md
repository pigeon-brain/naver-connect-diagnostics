# Third-party components and scope

Project source is offered under GPL-3.0; see LICENSE. This is an independent project, not an official Naver/Npay/LineageOS product. Android SDK, Platform-Tools, JDK and Python are external build/runtime dependencies, not bundled or relicensed here. No stock firmware, original APKs, extracted fonts, signing keys, or device backup material is distributed. Public app builds use Android/system web fonts and project vector resources. Hostnames, tokens, paired devices and service configuration must be supplied locally.
